# Description

This project realize the SPH solver in CPU, but is not effective. Further more, we add the visualization effect on water surface by opengl.

# How to complie

1. Only can run on windows. Compiling on windows is strongly recommended. Further more, your computer must have a NVIDIA graphics card.

2. Please download VisualStudio2022.

3. Open sln file in VisualStudio2022, and then compile. May need to change the extened instruction set or OpenMP option.
